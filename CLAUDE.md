# ETHnym

Native iOS Ethereum wallet in SwiftUI, the iPhone counterpart of `ethnym-android-app`. See README.md for setup and layout.

## Conventions
- The Xcode project is generated by XcodeGen from `project.yml` and not committed. Run `xcodegen generate` after adding or removing files.
- UI lives in `App/`. All non-UI logic lives in `Packages/EthnymKit`, with tests (`swift test`).
- Swift 6 language mode, iOS 18 deployment target. The app target defaults to main-actor isolation; EthnymKit doesn't, and marks CPU-heavy crypto `@concurrent`.
- Don't hand-roll cryptography. Use web3.swift, MnemonicSwift, libsecp256k1, CryptoKit or CommonCrypto (see README).
- Keystore and backup JSON must stay byte-compatible with the web wallet (`ox` keystores, `um-wallet-backup`). The fixtures in `Packages/EthnymKit/Tests/EthnymKitTests/Fixtures` were generated by the web wallet's own `ox`/`viem`.
- Style: JetBrains Mono everywhere (`Font.mono`), black and white (`.primary` tint, red only for errors and destructive actions), full addresses, never truncated, shown unbroken (`AddressText`), critically damped springs (`Animation.house`).
- UI tests run with `-demo`, `-empty` and `-offline` launch arguments. A test that signs must run `-offline` so it can't broadcast.
